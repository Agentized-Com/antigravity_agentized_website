AI Tool Test

This page exists to test whether a chat model can discover and use a real tool-like endpoint on a site.

Tool manifest

Available at:

/api/tool/manifest

Example response:

{
  "name": "Agentized AI Tool Test",
  "description": "Allows a client to search a demo catalogue and create a demo product.",
  "version": "1.0.0",
  "endpoints": [
    { "name": "search_catalogue", "method": "GET", "path": "/api/tool/search?q=MT2" },
    { "name": "create_product", "method": "POST", "path": "/api/tool/create" }
  ]
}

Shared 8x8 board

Everyone viewing this page sees the same state. A tool call updates the board globally.

Current board color: #ff6600

Example tool call:

POST /api/tool/paint
{
  "row": 3,
  "col": 5,
  "color": "#00cc99"
}

Function test URLs

  • GET /api/tool/search?q=MT2
  • POST /api/tool/create with JSON like {"name":"Demo Product","price":99,"category":"test","sku":"DEMO1"}
  • POST /api/tool/paint with JSON like {"row":3,"col":5,"color":"#00cc99"}

Prompt to try in chat

Ask the model:

Use the Agentized AI Tool Test tool to paint row 3 column 5 green and tell me when it is done.

Then try:

Create a product called Demo Product for $99 in the Agentized test tool.
